## 2. Logic Chain

1. **Race Conditions / Double Bookings**: From Observation 1, because `PhienBan` is not declared as a concurrency token in EF Core, database update statements generated by EF Core will not verify that the value of `PhienBan` matches the original value fetched. Thus, concurrent reservation attempts will silently overwrite each other, allowing the same seat to be booked multiple times.
2. **Instant Timer Expiration**: From Observation 2, SQLite stores `GiuDenLuc` as an unspecified DateTime kind. When serialized, it outputs a date string without `Z` (UTC marker). The client browser parses this string in local system time, causing it to compute a hold expiration date in the past. This resets the timer to `00:00` immediately on page reload.
3. **Checkout Mismatch Block**: From Observation 3, since the backend API does not return a property named `gheId`, accessing `seat.gheId` resolves to `undefined`. Thus, all passenger seat assignments are saved with a `seatId` of `undefined`. During checkout, this results in an empty selection array (`selectedSeatIds.length === 0`), triggering the block alert `"Vui lòng chọn ít nhất 1 ghế trước khi thanh toán."`.
4. **JavaScript Runtime Crashes**: 
   - From Observation 4, because `authService.getSessionId` is not defined, proceeding to checkout throws a `TypeError: authService.getSessionId is not a function`, resulting in a blank white screen.
   - From Observation 5, accessing index `[0]` of the result of `.match(/\d+/)` on a non-numeric seat label (where the match returns `null`) throws a `TypeError`, crashing the React render loop.
5. **Layout Overflows**: From Observation 6, 6 seats (240px) + 5 gaps (40px) + 1 aisle (32px) = 312px required width. The maximum available width inside the glass cabin is `400px * 0.8 - 60px` = 260px. This causes the seats to extend beyond the borders of the cabin. The lack of media queries also causes horizontal scrolling on viewports under 1000px.
